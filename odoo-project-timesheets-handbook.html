👋 Welcome aboard!

Odoo Project is where the team plans and tracks work, and Timesheets is how we record the hours we spend on it. Together they answer the two questions a consultancy lives by: “what needs doing?” and “where did our time go?” Learn the handful of ideas below and you can run any project board.

🧠 Read this first — the one big idea

Everything is a task inside a project. A project is the container (a client, an initiative); tasks are the pieces of work inside it that move across stages from “to do” to “done”. Log your hours as timesheets on those tasks, and Odoo shows planned-vs-real time automatically.

1 What Project Is

Organise work into projects and tasks, and see status at a glance — no “where are we?” emails.

Odoo Project turns work into visible, trackable items. Each project holds many tasks, and each task sits in a stage (a kanban column) that shows how far along it is. Anyone can open the board and instantly see what is in progress, what is blocked, and what is done.

📁 Project

A container for related work — often one client or initiative.

✅ Task

A single piece of work: “Configure Helpdesk SLA”.

🗂️ Stage

A column (To Do → In Progress → Done) showing progress.

⏱️ Timesheet

Hours logged against a task.

2 Projects & Stages

Create the container and shape its columns to match how your team works.

Project → New

Give the project a name, optionally link a customer, and choose whether it allows timesheets and billing. Each project has its own stages — rename or add columns (e.g. To Do, In Progress, Review, Done) so the board mirrors your real process.

ℹ️

A project can be tied to a customer and a sales order, so tasks and logged time trace straight back to what was sold and can be billed.

4 Kanban Stages & Task Lifecycle

Work flows left-to-right across the board. You move it by dragging.

Drag a card from one stage to the next as work progresses. Each card also has a kanban state — a small traffic light: green “ready”, red “blocked”, or grey “in progress” — to flag problems without moving the card.

1To Do — captured, not started.
2In Progress — someone is actively working it.
3Review / Done — finished, or awaiting a check.
ℹ️

Personal stages let each person organise their own view of tasks without changing the shared project columns.

5 Timesheets — logging time

Record how long work actually took. This is what makes billing and estimates honest.

With the Timesheets app installed and the project set to allow it, every task gets a Timesheets tab. Add a line with the date, a description and the hours — or use the Grid view to fill a whole week at once.

Project task → Timesheets tab → Add a line  ·  or   Timesheets app → Grid
💡

Use the built-in timer (start/stop on a task) to capture time as you work instead of guessing at the end of the day.

6 Planning & Progress

Estimate vs reality, at a glance.

Each task compares planned hours (your estimate) with effective hours (what you logged). A progress bar shows how much of the estimate is used — so you spot a task about to blow its budget while there is still time to react.

TermPlain meaning
Planned / Allocated hoursWhat you estimated the task would take.
Effective hoursWhat was actually logged via timesheets.
RemainingPlanned minus effective — budget left.

7 Collaboration & Reporting

Keep the conversation on the work, and read the numbers that come out of it.

Every task has the chatter (Chapter 7 of the Getting Started handbook): message the customer, log internal notes, @mention colleagues, attach files and schedule follow-up activities — all pinned to the task.

Reports worth knowing

📊 Task Analysis

Counts and status of tasks by project, stage, assignee.

⏱️ Timesheets Analysis

Hours by person, project or task — the billing view.

📉 Burndown

Work remaining over time — are we on track to finish?

🗓️ Project dashboard

Per-project overview of open work and logged time.

★ Plain-English glossary

The words you'll keep hearing — decoded.

Project
A container for related tasks — usually a client or initiative.
Task
A single piece of work that moves across stages.
Sub-task
A smaller task nested under a parent task.
Stage
A kanban column showing how far along a task is.
Kanban state
A task’s traffic light: ready (green), blocked (red) or in progress.
Personal stage
Your own private way to organise tasks, separate from shared columns.
Timesheet
A logged entry of hours spent on a task.
Planned / Effective hours
The estimated effort vs the hours actually logged.
Dependency
A rule that one task can’t start until another is done.
Billable
Whether logged time can be invoiced to a customer.
