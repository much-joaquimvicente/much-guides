AI Automated Actions — User Guide

Let Odoo automatically ask an AI (ChatGPT, Claude, Gemini or Mistral) to read a record and write something useful back — no coding needed. Written for a new team member.

1. What is this?

This module plugs a generative AI straight into Odoo. When something happens on a record — an order is confirmed, a document is attached — Odoo can automatically send that record's data to an AI model and get back written text. That answer is then posted into the record's chatter, saved into a field, or turned into a to-do activity, all inside Odoo.

Why it exists: teams spend a lot of time on repetitive reading-and-writing — summarising a long email thread, drafting a reply, pulling key facts out of a PDF. This hands those tasks to an AI automatically, triggered by events you already track, so nobody has to copy-paste text into a separate chatbot.

Three moving parts. A Provider (the AI company + your key) → a Server Action (the recipe: which model, what to ask, where the answer goes) → an Automation Rule (the trigger that decides when it runs). Set them up in that order.

A few words you'll hear

AI Provider
The company whose AI you use — OpenAI, Anthropic (Claude), Google Gemini or Mistral. This is where you paste your API key.
AI Model
A specific "brain" from a provider (e.g. Claude 3.5 Haiku). Each has settings for creativity, length, and whether it can read files.
Server Action (Generative AI)
The AI recipe: which model, the prompt, what data to include, and where to put the answer.
Automation Rule
The trigger that decides when the recipe runs (e.g. "when a record is created").
Prompt Template
The instructions you write for the AI. It can pull live data with placeholders like {{ object.name }}.
AI Log
A record of what the AI did and any errors, under AI > Logs — your first place to look if nothing happened.
