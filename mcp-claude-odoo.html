AI Assistant (MCP) — connect Claude to Odoo

What MCP is, why we use it, and the full setup to let Claude read & act on your Odoo data. Written for a junior technical joiner.

⚠️ Setup has changed — Odoo 18 & 19. On Odoo 18 and 19 the MCP server is built into Odoo, so the configuration is now much simpler: all you need is your Odoo URL with /mcp appended (for example https://your-instance.odoo.com/mcp). The full manual setup described below is only required for other Odoo versions.

1. What is MCP, in plain words

MCP = Model Context Protocol. It's a technical standard introduced by Anthropic (the company behind Claude). It's a common way to connect an AI assistant — Claude, but also other AI tools — to an external system, so the AI can actually read and work with that system's data.

Claude Desktop
the AI assistant
↔
MCP server
runs on your computer
↔
Odoo
your data + code

Example: connected to Odoo, you can ask "give me all January invoices above €10,000" and Claude pulls the data and summarises it for you.

2. Why we set this up

Today you have the code and the test environments — but the AI can't see the data. MCP adds that data layer, so Claude can combine code + real data. That's far better for investigating issues (e.g. "explain why this code was written this way, using the code and the data").

Permissions. much. also publishes a free Odoo Marketplace module that sits on top of this and controls what the AI can touch (e.g. Sales but not Accounting; read-only vs create/update). That's configured on the Odoo side. Through MCP, you get exactly the permissions your own Odoo user already has in the UI — nothing more.
💡 Which client? The MCP server runs locally (on the machine where Claude Desktop is installed), not on the Odoo server. Claude Desktop is recommended for releases (it holds reusable skills — pre-made prompts). Any MCP-compatible client is configured in a similar way.

3. Set up the AI assistant with Claude Desktop

1
Install UV on your computer
📍 Terminal
macOS
$curl -LsSf https://astral.sh/uv/install.sh | sh
Windows
>powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

💡 UV gives you uvx, which Claude will use to run the Odoo MCP server.

2
Find the uvx path
📍 Terminal

You'll need the full path in the config later.

$which uvx

Usually returns something like /Users/yourusername/.local/bin/uvx. Copy it.

3
Restart your terminal
📍 Terminal

Close and reopen your terminal so the new uv is on your PATH.

4
Open the Claude Desktop config
📍 Claude Desktop → User ▸ Settings ▸ Developer

Click Edit Config to open claude_desktop_config.json. Open it in VS Code so the JSON stays correctly formatted.

5
Add the odoo server to mcpServers
📍 claude_desktop_config.json

Add (or merge) this block, then fill in your own values:

{ "mcpServers": { "odoo": { "command": "YOUR_UVX_PATH", "args": ["mcp-server-odoo"], "env": { "ODOO_URL": "YOUR_ODOO_URL", "ODOO_DB": "YOUR_ODOO_DB", "ODOO_USER": "YOUR_ODOO_USER_EMAIL", "ODOO_API_KEY": "YOUR_ODOO_API_KEY" } } } }

Values: command = the uvx path from step 2 · ODOO_URL = your Odoo instance URL (mind the trailing slash) · ODOO_DB = database name (optional, auto-detected if omitted) · ODOO_USER = your Odoo login email · ODOO_API_KEY = the key from the next step.

6
Generate your Odoo API key
📍 Odoo → Settings → Users → (your user) → Account Security

Click New API Key (you may need to confirm your password first). Name it e.g. Claude Desktop, set an expiry (~1 year), and copy the key into ODOO_API_KEY.

💡 A key is the recommended auth. Alternatively you can use ODOO_USER + ODOO_PASSWORD instead of a key.

7
Optional trick — grant read access to everything you can see
📍 Same config, inside env

Because the exact Odoo-side permission config may be unknown, you can add this line so Claude can read anything your user already has access to. Add it right after ODOO_API_KEY (watch the JSON commas!):

"ODOO_YOLO": "read"

This only lets the AI do what you are already allowed to do — it doesn't grant new permissions.

8
Save & restart Claude Desktop
📍 Claude Desktop

Save the file and fully restart Claude Desktop.

9
Check the status
📍 Settings ▸ Developer

Running ✅ = success, start asking Claude about your Odoo data. Failed ❌ = click View Logs, copy the text, and paste it to Claude — it'll help you troubleshoot.

4. Environment variables

VariableRequiredDescription
ODOO_URLYesYour Odoo instance URL.
ODOO_API_KEYYes*API key (recommended auth method).
ODOO_USERYes*Login email (with ODOO_PASSWORD, if not using a key).
ODOO_PASSWORDYes*Password (if not using a key).
ODOO_DBNoDatabase name (auto-detected if omitted).

* Use either ODOO_API_KEY, or both ODOO_USER and ODOO_PASSWORD.

Remote / web clients. Add "--transport", "streamable-http", "--port", "8000" to args and connect the client to http://localhost:8000/mcp/.

5. Verify the scheduled action

In Odoo, go to Settings ▸ Technical ▸ Automation ▸ Scheduled Actions and confirm MCP Log Cleanup exists and is active. It runs once a day and deletes log entries older than the Log Retention (days) setting (nothing is deleted if retention is 0).

✅ You're ready. You can now query and manage your Odoo data through your AI assistant — within the permissions your user has.
