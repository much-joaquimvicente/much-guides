Procuros — testing setup

How to set up two companies and test the full Procuros order flow (Buyer ↔ Seller) end to end.

Before you start. Installing the module is the same as the Odoo.sh instance install — see the Install an Odoo.sh instance guide. Do everything below after you have logged into the testing Odoo.sh environment. Credentials come from 1Password (Procuros Buyer / Seller / Supplier Credentials).
💡 Remember — each company needs a Warehouse configured, and an Accounting setup so you can have VAT. Without them the order flow won't complete.
📖 Full instructions (KB). All the steps above are documented in the Knowledge base: erp.muchconsulting.de/odoo/knowledge/2929/knowledge/2957
