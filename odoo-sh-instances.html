Installing an instance on Odoo.sh

How to spin up a fresh staging instance on Odoo.sh and wire it to a GitHub submodule (a much. module you want to work on).

Access to Odoo.sh Access to the GitHub repository The right Odoo version in mind
The big idea. Odoo.sh runs the Odoo instance; GitHub holds the module code. To let Odoo.sh pull a private repo, the two must shake hands with a deploy key: Odoo.sh generates a key → you paste it into the GitHub repo → GitHub now trusts Odoo.sh. Then Odoo.sh can add that repo as a submodule and build the instance.
🔑 Remember — the deploy key is the handshake. If the build can't fetch the submodule, it's almost always because the key wasn't added to the GitHub repo (or was added to the wrong repo). And always stay on your staging branch while doing this.
