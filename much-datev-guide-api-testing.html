Testing the DATEV Integration

Run the whole pipeline end-to-end against our test DATEV clients — configure, push data from Odoo, then open DATEV in Citrix to watch it arrive.

much. GmbH · Odoo 19 · DATEVconnect · internal use only
🧠 The one big idea

Testing = push real financial data through the API and log into the DATEV test environment to confirm it landed. The quick path is to use an existing product test instance — they all already have a configured DATEV integration. Only if you're testing setup itself do you build a new integration with one of our test clients. Two things you can't skip: the DATEV SmartLogin (QR) for the access token, and — to view DATEV — the DATEV USB token that must be plugged in before you log in to Citrix.

📚

Reference docs: the full configuration walkthrough lives at erp.muchconsulting.de/odoo/knowledge/1887. This page is the hands-on test playbook that sits on top of it.

0 What you need before you start

A mix of an Odoo instance, two phone apps, and some hardware for the Citrix side.

🧩 A test instance + client

Easiest: an existing product test instance (they all have a DATEV integration already). Or build a new integration against a much. test DATEV client (numbers below).

📱 DATEV SmartLogin app

On your phone — used to approve the access token by scanning a QR code.

📱 MobilePass+ app

On your phone — the 2-factor token app for logging in to the Citrix DATEV environment.

🖥️ Citrix + USB token

Citrix Workspace installed, plus the DATEV USB token (“pen”) and a completed KUHN-IT activation.

💡

Two different phone apps, two different jobs: SmartLogin authorises the API token in Odoo; MobilePass+ is the 2FA for the DATEV Citrix login. Don't mix them up.

A Set up & push data from Odoo

Configure the integration against a test client, authorise it, then export.

1 · Create the integration with a test client

In Germany every company has a consultant number (Beraternummer — the tax-advisor ID) and a client number (Mandantennummer — the client within that advisor). These are standard Odoo fields the integration reuses. Use our test values:

Consultant no.
5671448
Client no.
10001  ·  10002  ·  10003

Pick one client number and create the integration. If you're practising, do the full API setup from scratch — register the client in the DCS and add the redirect URL in the DATEV portal (that's the onboarding guide).

2 · Get an access token via SmartLogin (QR)

1

Click “Get Access Token”

A QR code appears (this window is only allowed because your instance URL is registered as a redirect).

2

Scan with DATEV SmartLogin on your phone

Approve the permissions. The token turns green = valid.

3

Click “Enable Integration”

The integration is now active and will export on schedule.

3 · Configure the export settings (quick reference)

SettingWhat to pick for a test
Export frequencydaily or monthly — daily is handy for testing.
Accounting journalsPick whichever journals you want to test — e.g. sales · purchase · bank.
Batch sizeGroups entries so big exports don't time out. Default is fine.
Export start dateDefaults to the day you created the integration; set it back to catch existing data.
Master dataThe customers + vendors list (partners).
PDF documentsMandatory = an invoice with no PDF is skipped; optional = exported without the PDF.

4 · Export to the API

In the integration, run Export the API from a start date until now (e.g. 1 April → today). This pushes the sales/purchase/bank data straight to the DATEV API — it's not a download. A cron job named export data also runs this automatically.

🔎

Check the logs. They show what was sent and the per-timeframe status — e.g. Partner export successful, Account move export successful — and any failures (a missing PDF shows as a REST API multipart upload fault). Open a failed entry to see exactly what did and didn't go.

B Open DATEV (Citrix) to see the data

The DATEV test environment runs inside Citrix. First-time setup, then login — and the one rule that trips everyone up.

One-time setup

1

Install Citrix Workspace

The client that opens the virtual DATEV machine.

2

Install “MobilePass+” on your phone

The 2-factor token app for the DATEV login.

3

Wait for the KUHN-IT confirmation email

It activates your 2-factor authentication token.

4

Open the email link & scan the QR in MobilePass+

The app guides you through the rest of activation.

🔌

Plug the USB token in BEFORE you log in. The DATEV USB stick (the “pen” / hardware token) must be inserted before the Citrix login, or DATEV won't recognise the key — “USB stick always goes before login.” If it says the pen isn't detected, re-seat it and try again.

C Find your client & pull in the API data

Now open the client you exported to and bring in what the API sent.

1

Open your test client (Mandant)

DATEV lists all the clients. Open the one you pushed data to (e.g. 10001) — that gives you access to all its financial data for the current year (2026).

2

Open Buchführung for the current year

Go into the bookkeeping / Buchung area for the current year of your client.

3

Click “Mandant ergänzen”

This pulls in the data shared via the API — the export you just sent from Odoo now shows up in DATEV.

🎉

If your Odoo export logs said successful and the entries appear here after Mandant ergänzen, the full round-trip works — Odoo → DATEV API → tax-advisor's books.

4 Troubleshooting

SymptomCauseFix
“Could not get access token” (a customer's instance)Not subscribed / user lacks rightsHave them confirm their subscription is active and their user has access to the needed services (documented at the knowledge link above).
DATEV says the pen isn't detectedUSB token inserted too late / looseLog out, re-insert the DATEV USB token, then log in again — token first, always.
Export entry failed in the logse.g. missing PDF (multipart upload fault)Open the failed log entry to see what was/wasn't sent; add the PDF or set PDF to optional and re-export.
Client doesn't show the key / rightsTiming — rights can take a moment to propagateWait a little and retry; the “Check clients” endpoint verifies each client's rights.
